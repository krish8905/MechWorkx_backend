# MechWorkx_backend

http://localhost:5000/auth/signup => create account

http://localhost:5000/auth/login => login 

http://localhost:5000/auth/verify-otp => verify OTP
http://localhost:5000/api/jobs/send-otp => when click on the create job 
http://localhost:5000/api/jobs/verify-otp-submit => verify OTP for job 

http://localhost:5000/api/jobs/ongoing => details of job (GET)

http://localhost:5000/api/bids/submit => submite bids (vendor)

http://localhost:5000/api/bids/submit => Submit  a Bid (vednor)
http://localhost:5000/api/bids/award => customer see and accept 

http://localhost:5000/api/progress/job-id /accept => vendor accept 

http://localhost:5000/api/progress/job-id /update => vendor update job

http://localhost:5000/api/dash/customer=> display the  dashboard of customer (GET)
http://localhost:5000/api/dash/vednor=> display the  dashboard of vendor (GET)
